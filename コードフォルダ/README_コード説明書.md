# コードフォルダ 説明書

作成日: 2026-10-02　／　更新日: 2026-10-07

## このフォルダのコードでできること

圧力センサの立ち上がり抽出結果をまとめたCSV（`*_summary_rise_start_results.csv`）を読み込み、CH03–CH04 区間の物理量を算出して、CSV・Excel・PNGグラフに出力します。**NR500 と Futaba のデータは同じ構成なので、どちらも同じコードで処理します。**

| 量 | 単位 | 算出式 |
|---|---|---|
| 時間差 ΔT34 | s | CH04立ち上がり時間 − CH03立ち上がり時間 |
| 圧力差 ΔP34 | Pa | (CH03圧力@CH04立ち上がり時 − CH04立ち上がり圧力) × 10⁶ |
| 流速 V34 | mm/s | L34 / ΔT34 |
| 流路断面積 A | mm² | キャビ厚 h × 40 |
| 流量 Q34 | mm³/s | V34 × A |
| 樹脂粘度 η34 | Pa・s | ΔP34 · A · h² / (12 · L34 · Q34) |
| せん断速度 γ34 | 1/s | 6 · Q34 / (A · h) |

L34 は CH03–CH04 のセンサ間距離で、**17.5 mm** です（01・02番に設定済み）。

## 対象ファイルの形式

### 共通ルール
- CSV（UTF-8 または Shift-JIS）で、1行目がヘッダー。
- 列名は**列の位置で付け直す**ため、列の順番が重要です（ヘッダーの文字そのものは問いません）。
- 温度は `元ファイル` 列から「数字＋℃」を読み取ります（例: `001_190℃_020_0.5mm.csv` → 190）。
- キャビ厚の列は数値（`0.5`）でも文字列（`0.5mm`）でも構いません。

### 8列形式（01・02）　例: `NR_summary_rise_start_results.csv`
| 列 | 内容 |
|---|---|
| 1 | 元ファイル |
| 2 | キャビ厚 |
| 3 | 射出速度[mm/s] |
| 4 | CH03_立ち上がり時間(s) |
| 5 | CH03_立ち上がり圧力(MPa) |
| 6 | CH04_立ち上がり時間(s) |
| 7 | CH04_立ち上がり圧力(MPa) |
| 8 | CH03圧力@CH04立ち上がり時(MPa) |

### 9列形式（01・02）　例: `NRall_summary_rise_start_results.csv`、`NR_3dataonly_summary_rise_start_results.csv`、`NR_5dataonly_summary_rise_start_results.csv`
| 列 | 内容 | 01・02番での扱い |
|---|---|---|
| 1〜7 | 8列形式と同じ | 同じ |
| 8 | 立ち上がり時間差(s)（全行で CH04−CH03 と一致） | 計算には使わず、そのまま保持 |
| 9 | 先行列圧力@後発列立ち上がり時(MPa) | 「CH03圧力@CH04立ち上がり時(MPa)」として計算に使う |

### 13列形式・15列形式（新しいサブ抽出データ。01・02は未対応）　例: `pp_NRall_summary_rise_max_pressure_results_2.csv`
1〜9列は9列形式と同じです（列名も同じ）。10列目以降が、抽出の種類によって違います。今の01・02は列数が8か9のときしか列名を付け直さないため、このファイルはセル2で止まります（注意点 8）。

| 列 | 13列形式（射出圧一定値時＝V01横ばい終点） | 15列形式（最大値） |
|---|---|---|
| 10 | V01横ばい終点時間(s) | CH03_最大圧力(MPa) |
| 11 | CH03圧力@V01横ばい終点(MPa) | CH03_最大圧力時間(s) |
| 12 | CH04圧力@V01横ばい終点(MPa) | CH04_最大圧力(MPa) |
| 13 | 先行列-後発列圧力差@V01横ばい終点(MPa) | CH04_最大圧力時間(s) |
| 14 | – | 最大圧力差(MPa) |
| 15 | – | 先行列圧力@後発列最大時(MPa) |

### 12列形式（03のみ・旧キャビ）　例: `FUTABA1_summary_rise_start_results.csv`
元ファイル, キャビ厚, 射出率(cm³/s), CH02/CH03/CH04 の立ち上がり時間(s)・立ち上がり圧力(MPa), CH03圧力@CH04立ち上がり時, CH02圧力@CH03立ち上がり時, CH02圧力@CH04立ち上がり時（MPa）
元ファイル名は `002_0.5mm_190℃.csv` の形式です。

## 共通の使い方（01・02）

1. VS Code でノートブックを開く。
2. カーネルに `.venv` を選ぶ（pandas / matplotlib / xlsxwriter などはインストール済み）。
3. **上から順に**すべてのセルを実行する。セル2以降はセル1で読み込んだデータを使います。
4. セル1でファイル選択ダイアログが開くので、CSVを選ぶ。複数選択した場合はファイルごとに処理されます。ダイアログは最前面に出る設定ですが、見当たらないときは他のウィンドウの裏を確認してください。

### 出力ファイル（入力CSVと同じフォルダに作成。同名のファイルは上書き）

| ファイル | 作成するセル | 内容 |
|---|---|---|
| `{CSV名}_processed.csv` | セル4 | 01: 全行＋全算出列＋外れ値の列（6量の「中央値からのずれ(%)」と「外れ値判定」。注意点 6）。02: 各条件の最終ショット1行ずつ＋算出列 |
| `{CSV名}_processed_outliers_removed.csv` | セル4 | 01のみ: `_processed.csv` から外れ値の行を除き、平均・標準偏差を残ったショットで計算し直したもの（列は `_processed.csv` と同じ。注意点 6） |
| `{CSV名}_aggregated_summary.csv` | セル3-1 | 1条件1行の集約。01: 平均・標準偏差・幾何平均・幾何標準偏差。02: 最終ショットの値 |

| `graph_images_{CSV名}/<シート名>/*.png` | セル10 | Excelと同じグラフのPNG |

Excelのシートは「射出速度と時間差の関係」「射出速度と流速の関係」「射出速度と流量の関係」「射出速度と圧力差の関係」「せん断速度と樹脂粘度の関係（両対数）」の5つです。各シートには、キャビ厚ごとの温度別個別グラフと総合グラフ、最後に全データの総集編グラフが入ります。

## 各コードの詳細

### 01_全ショット平均_算出と可視化
（旧名: `Futaba_抽出から加工_新キャビ版(グラフは平均と標準偏差).ipynb`）
- キャビ厚・温度・射出速度の組合せでグループ化し、グループ内の全ショットから次を計算します。
  - 時間差・流速・流量・圧力差: 平均と標準偏差
  - せん断速度・樹脂粘度: 幾何平均と幾何標準偏差
- ショット数が条件ごとに違っても、行の並びが崩れていても正しく集計できます。データが1件しかない条件は警告を出します（標準偏差がNaNになるため）。
- 8列・9列の両形式に対応しています。9列形式では、CH04がCH03より先に立ち上がっている行数を警告します。
- 外れ値を判定します。
  - 各ショットについて、条件の中央値からのずれ(%)を計算します。
  - 測定値（時間差・圧力差）のずれが±10%を超えたショットを外れ値とし、`_processed.csv` の「外れ値判定」列に記録します。
  - 個別グラフには、各ショットを灰色の点で重ね、外れ値を赤×とファイル番号で示します。
  - `_processed.csv`・`_aggregated_summary.csv`・グラフの平均・標準偏差は、外れ値を含めたまま計算します。
  - 外れ値の行を除いて平均・標準偏差を計算し直した `_processed_outliers_removed.csv` も、あわせて出力します。詳しくは「注意点 6」を参照してください。

### 02_最終ショットのみ_算出と可視化
（旧名: `Futaba_10shot目のみ_抽出から加工_新キャビ版.ipynb` → `02_10ショット目のみ_算出と可視化.ipynb`）
- 条件（キャビ厚・温度・射出速度）ごとに**最後の1行だけ**を丸ごと使います。平均・標準偏差は計算しません。
- 最後の行に空欄があっても、他のショットの値は混ざりません（2026-10-03 修正）。
- グラフはエラーバーなしで、`aggregated_summary.csv` は条件ごとの値そのものです。
- 条件ごとのショット数が違う場合の動作は「注意点 5」を参照してください。
- 8列・9列の両形式に対応しています（2026-10-03 追加。読み込み関数は01と同じ）。

### 03_旧キャビ_3センサ用_算出と可視化
（旧名: `修士一年次作成_抽出から加工_最終版.ipynb`。修士1年次に作成）
- 旧キャビ（CH02・CH03・CH04の3センサ）用です。12列のCSVを読み、横軸は射出率(cm³/s)です。
- 区間23・34・24（L23 = 22.4、L34 = 33、L24 = 55.4 mm）の3区間について計算します。L34 = 33 は旧キャビの値です。
- 平均・標準偏差を出すのはせん断速度γ23だけです（9行ごと）。グラフは30行ごとのブロック単位で作ります。
- 出力ファイル名は01・02と同じ形式ですが、シート名は「射出率と〜の関係」です。
- 現行のCH03・CH04だけのデータには使えません。

## 注意点

### 1. CH04 が CH03 より先に立ち上がっているデータ（NRall の 0.5mm は修正済み）
計算式は「CH03 → CH04 の順に流れる」前提です。CH04 が先に立ち上がっている行があると、その行は次のようになります。

- 時間差・流速・流量が負になり、グラフ（縦軸は0から）に表示されない。
- せん断速度・樹脂粘度が負になり（01では幾何平均の計算で NaN になる）、両対数の粘度グラフに出ない。

旧 `NRall_summary_rise_start_results.csv`（注意点 7）では、もともと 0.5mm 条件の270行（27条件）がこの状態でした。2026-10-03 にデータ側で修正済みです。修正内容は次のとおりです（git diff で確認）。

- 0.5mm の270行で、CH03 と CH04 の「立ち上がり時間」と「立ち上がり圧力」を入れ替えた。
- 1〜3列目、8列目（立ち上がり時間差）、9列目（先行列圧力@後発列立ち上がり時）と、0.5mm 以外の行は変更していない。
- その結果、全行で CH03 が先に立ち上がり、8列目は CH04−CH03 と一致し、9列目は全行で「CH03 の圧力 @ CH04 立ち上がり時」を意味する。

新しい9列データで同じ現象があれば、01・02番がセル1で「警告: ○行でCH04がCH03より先に立ち上がっています」と表示します。その場合は、センサの配線やデータを確認し、今回と同じように修正してください。

2026-10-07 に追加したサブ抽出データ（注意点 8）の立ち上がりの列は、0.5mm も含めて全行で CH03 が先に立ち上がっています。ただし、バージンPPの最大値版の 0.5mm では、最大圧力の列に別の確認点があります（注意点 8 の (a)）。

### 2. 軸範囲の外にある点はグラフに描かれない
軸範囲はセル5の `MANUAL_AXIS_LIMITS` で固定されています。範囲の外に出た点やエラーバーは、警告なしにグラフから切れます。新しいデータ（材料・温度・射出速度が違うもの）を処理したら、`{CSV名}_aggregated_summary.csv` の最小値・最大値が「軸範囲の現在値」の表に収まっているか確認してください。収まっていなければセル5の値を広げます。01と02は同じ値にそろえておくと、グラフを比べやすくなります。

### 3. 出力は上書きされる
01・02（と03）は同じ名前で出力するため、同じCSVに別のノートブックを実行すると前の結果が上書きされます。両方の結果を残したい場合は、CSVを別フォルダにコピーしてから実行してください。

### 4. ノートブック内に残っている実行結果について
01番の出力はクリア済みです。02番と03番に残っている出力は、改名前に別のCSV（02: `NR_summary_rise_start_results.csv`、03: `FUTABA1_summary_rise_start_results.csv`）で実行したときのもので、NRall の結果ではありません。

### 5. 条件ごとのデータ数が異なる場合
NRall は全条件10ショットずつですが、条件ごとにショット数が違うデータも処理できます（03番を除く）。2026-10-03 に、件数を1〜15件にばらつかせ、一部の条件を丸ごと抜き、行の順序をシャッフルしたデータで、01・02番の動作を確認しました。

- **01番（全ショット平均）**: 対応しています。
  - 条件（キャビ厚・温度・射出速度）ごとに、その条件の全ショットで平均・標準偏差を計算します。行の並び順にも左右されません。
  - 個別グラフでは、条件ごとに1点と1本のエラーバーが描かれます。
  - データが1件しかない条件は標準偏差が計算できないため、点だけ描かれてエラーバーは出ません。セル2で「【警告】条件 (…) のデータ数が1件です」と表示されます。
  - データがない条件は点が出ず、線は前後の点を結びます。
  - 各点が何件の平均かは `_aggregated_summary.csv` には出ません。必要なら `_processed.csv` で条件ごとの行数を数えてください。
- **02番（最終ショットのみ）**: 各条件の**最後の行**を使います。
  - 10件の条件なら10ショット目ですが、7件なら7ショット目、15件なら15ショット目になります。
  - 元CSVで各条件の行がショット順に並んでいることが前提です。NRall はファイル番号順なので満たしています。
- **03番（旧キャビ）**: 対応していません。行の位置で区切っているため（標準偏差は9行ごと、温度の系列は10行ごと、キャビ厚は30行ごと）、件数が違うと別の条件が混ざります。

### 6. 外れ値の見つけ方（01番）
グラフで平均値の位置がおかしい条件があったら、次の手順で原因のショットを探します。

1. **個別グラフ（エラーバー付き）を見る。** 各ショットが灰色の点で、外れ値が赤×で描かれています。赤×の横に、外れたショットのファイル番号（`元ファイル` の先頭の番号。例: `079, 080`）が表示されます。
2. **`{CSV名}_processed.csv` を開き、「外れ値判定」列でフィルタする。** 外れ値の行には、影響を受ける量の名前（例: `時間差・流速・流量・せん断速度・樹脂粘度`）が入っています。外れていない行は空欄です。
3. **「〜_中央値からのずれ(%)」の列を見る。** どの量がどちら向きに何%ずれたかが分かります。

**判定方法**
- 条件（キャビ厚・温度・射出速度）ごとに中央値を求め、各ショットのずれ(%)を計算します。
- 測定値である**時間差・圧力差**のどちらかが ±10%（`OUTLIER_THRESHOLD_PERCENT`）を超えたショットを外れ値とします。
- そこから計算する量にも同じ印を付けます。
  - 時間差が外れた場合: 時間差・流速・流量・せん断速度・樹脂粘度
  - 圧力差が外れた場合: 圧力差・樹脂粘度
- データが3件未満の条件は判定しません（どれが外れているか決められないため）。
- **平均±3σを使わない理由**: 外れたショット自身が平均と標準偏差を引っ張るため、10ショット程度では外れ値が3σを超えられません（理論上の最大は約2.85σ）。そのため、外れ値に引っ張られにくい中央値を基準にしています。NRall のふつうの条件のばらつき（変動係数）は約2%なので、±10%はかなり大きなずれです。
- **樹脂粘度を、樹脂粘度自身のずれで判定しない理由**: 樹脂粘度は「圧力差×時間差」に比例し、2つのずれは同じ向きに出ます（NRall で相関0.92）。そのため、時間差+5%・圧力差+5%のような普通のショットでも、樹脂粘度は10%以上ずれます（樹脂粘度自身で判定すると、NRall で109行が外れ値になる）。
- 「中央値からのずれ(%)」の列は6量すべてについて出力しているので、樹脂粘度自身のずれも確認できます。

**読み方**
- 1〜2ショットだけが赤 → そのショットが平均を引っ張っています。
  - 例: NRall の 0.5mm/190℃/280mm/s では、079番（時間差+31%、圧力差+67%）と080番（+16%、+29%）が外れ値です。
- 大半のショットが赤 → 1本の異常ではなく、条件全体がばらついています。
  - 例: 0.5mm/190℃/320mm/s では、10ショット中8ショットが外れ値です。
- NRall 全体では、20行（12条件）が外れ値と判定されます（2026-10-03 確認）。

軸範囲の外にあるショットはグラフに描かれません（注意点 2）。NRall では、すべてのショットが軸範囲内に収まっています。

**外れ値を除いた版（`{CSV名}_processed_outliers_removed.csv`）**

01番を実行すると、`_processed.csv` と同じフォルダに、外れ値の行を除いた版も出力されます。
- 「外れ値判定」に何か入っている行（時間差・圧力差のどちらかが外れたショット）を除きます。
- 平均・標準偏差・幾何平均・幾何標準偏差の列は、残ったショットだけで計算し直します。
- 列の並びは `_processed.csv` と同じです。外れ値がなかった条件の値は、`_processed.csv` と同じです。
- 外れ値の判定は、全ショットで1回だけ行います。除いた後に、もう一度判定し直すことはしません。
  - 「中央値からのずれ(%)」の列は、判定したときの値（全ショットの中央値が基準）のままです。
  - 「外れ値判定」の列は、すべて空欄になります。
- 外れ値がないファイルでも出力されます（中身は `_processed.csv` と同じ行になります）。

使うときの注意点は次のとおりです。
- 外れ値を除くのは、このファイルだけです。`_aggregated_summary.csv`・グラフ・Excel は、外れ値を含めたままの平均・標準偏差です。どちらの値を使うかは、外れ値の一覧を見て判断してください。
- 大半のショットが外れ値の条件では、残ったわずかなショットだけで平均・標準偏差を計算します。標準偏差が小さく出ても、ばらつきが小さいという意味ではありません。
  - 例: NRall の 0.5mm/190℃/320mm/s は、10ショット中2ショットしか残りません。時間差の標準偏差は 0.0023 s から 0.00007 s になります。
- 除いた後に1ショットしか残らない条件では、標準偏差が空欄（NaN）になります。全ショットが外れ値の条件は、ファイルから消えます（NRall・3data・5data には、どちらもありません）。

NRall・3data・5data での除外の結果は、次のとおりです（2026-10-04 確認）。

例として、NRall の 0.5mm/190℃/280mm/s（079番・080番を除外）では、次のように変わります。

- 圧力差の平均: 1.92×10⁶ Pa → 1.75×10⁶ Pa（−9.2%）
