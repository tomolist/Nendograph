# コードフォルダ 説明書

作成日: 2026-10-02　／　更新日: 2026-10-03

## このフォルダのコードでできること

圧力センサの立ち上がり抽出結果をまとめたCSV（`*_summary_rise_start_results.csv`）を読み込み、CH03–CH04 区間の物理量を算出して、CSV・Excel・PNGグラフに出力します。**NR500 と Futaba のデータは同じ構成なので、どちらも同じコードで処理します。**

| 量 | 単位 | 算出式 |
|---|---|---|
| 時間差 ΔT34 | s | CH04立ち上がり時間 − CH03立ち上がり時間 |
| 圧力差 ΔP34 | Pa | (CH03圧力@CH04立ち上がり時 − CH04立ち上がり圧力) × 10⁶ |
| 流速 V34 | mm/s | L34 / ΔT34 |
| 流路断面積 A | mm² | キャビ厚 h × 40 |
| 流量 Q34 | mm³/s | V34 × A |
| 樹脂粘度 η34 | Pa・s | ΔP34 · A · h² / (12 · L34 · Q34) |
| せん断速度 γ34 | 1/s | 6 · Q34 / (A · h) |

L34 は CH03–CH04 のセンサ間距離で、**17.5 mm** です（01・02番に設定済み）。

## 対象ファイルの形式

### 共通ルール
- CSV（UTF-8 または Shift-JIS）で、1行目がヘッダー。
- 列名は**列の位置で付け直す**ため、列の順番が重要です（ヘッダーの文字そのものは問いません）。
- 温度は `元ファイル` 列から「数字＋℃」を読み取ります（例: `001_190℃_020_0.5mm.csv` → 190）。
- キャビ厚の列は数値（`0.5`）でも文字列（`0.5mm`）でも構いません。

### 8列形式（01・02）　例: `NR_summary_rise_start_results.csv`
| 列 | 内容 |
|---|---|
| 1 | 元ファイル |
| 2 | キャビ厚 |
| 3 | 射出速度[mm/s] |
| 4 | CH03_立ち上がり時間(s) |
| 5 | CH03_立ち上がり圧力(MPa) |
| 6 | CH04_立ち上がり時間(s) |
| 7 | CH04_立ち上がり圧力(MPa) |
| 8 | CH03圧力@CH04立ち上がり時(MPa) |

### 9列形式（01・02）　例: `NRall_summary_rise_start_results.csv`
| 列 | 内容 | 01・02番での扱い |
|---|---|---|
| 1〜7 | 8列形式と同じ | 同じ |
| 8 | 立ち上がり時間差(s)（全行で CH04−CH03 と一致） | 計算には使わず、そのまま保持 |
| 9 | 先行列圧力@後発列立ち上がり時(MPa) | 「CH03圧力@CH04立ち上がり時(MPa)」として計算に使う |

### 12列形式（03のみ・旧キャビ）　例: `FUTABA1_summary_rise_start_results.csv`
元ファイル, キャビ厚, 射出率(cm³/s), CH02/CH03/CH04 の立ち上がり時間(s)・立ち上がり圧力(MPa), CH03圧力@CH04立ち上がり時, CH02圧力@CH03立ち上がり時, CH02圧力@CH04立ち上がり時（MPa）
元ファイル名は `002_0.5mm_190℃.csv` の形式です。

## 共通の使い方（01・02）

1. VS Code でノートブックを開く。
2. カーネルに `.venv` を選ぶ（pandas / matplotlib / xlsxwriter などはインストール済み）。
3. **上から順に**すべてのセルを実行する。セル2以降はセル1で読み込んだデータを使います。
4. セル1でファイル選択ダイアログが開くので、CSVを選ぶ。複数選択した場合はファイルごとに処理されます。ダイアログは最前面に出る設定ですが、見当たらないときは他のウィンドウの裏を確認してください。

### 出力ファイル（入力CSVと同じフォルダに作成。同名のファイルは上書き）

| ファイル | 作成するセル | 内容 |
|---|---|---|
| `{CSV名}_processed.csv` | セル4 | 01: 全行＋全算出列。02: 各条件の最終ショット1行ずつ＋算出列 |
| `{CSV名}_aggregated_summary.csv` | セル3-1 | 1条件1行の集約。01: 平均・標準偏差・幾何平均・幾何標準偏差。02: 最終ショットの値 |
| `graph_output_{CSV名}.xlsx` | セル10 | グラフ画像を貼り付けたExcel（5シート） |
| `graph_images_{CSV名}/<シート名>/*.png` | セル10 | Excelと同じグラフのPNG |

Excelのシートは「射出速度と時間差の関係」「射出速度と流速の関係」「射出速度と流量の関係」「射出速度と圧力差の関係」「せん断速度と樹脂粘度の関係（両対数）」の5つです。各シートには、キャビ厚ごとの温度別個別グラフと総合グラフ、最後に全データの総集編グラフが入ります。

## 各コードの詳細

### 01_全ショット平均_算出と可視化
（旧名: `Futaba_抽出から加工_新キャビ版(グラフは平均と標準偏差).ipynb`）
- キャビ厚・温度・射出速度の組合せでグループ化し、グループ内の全ショットから次を計算します。
  - 時間差・流速・流量・圧力差: 平均と標準偏差
  - せん断速度・樹脂粘度: 幾何平均と幾何標準偏差
- ショット数が条件ごとに違っても、行の並びが崩れていても正しく集計できます。データが1件しかない条件は警告を出します（標準偏差がNaNになるため）。
- 8列・9列の両形式に対応しています。9列形式では、CH04がCH03より先に立ち上がっている行数を警告します。

### 02_10ショット目のみ_算出と可視化
（旧名: `Futaba_10shot目のみ_抽出から加工_新キャビ版.ipynb`）
- 条件（キャビ厚・温度・射出速度）ごとに**最後の1行だけ**を使います。平均・標準偏差は計算しません。
- グラフはエラーバーなしで、`aggregated_summary.csv` は条件ごとの値そのものです。
- 条件ごとの行数が違っても動きますが、「最後の行」が使われるので、行の順番（ショット順に並んでいること）に注意してください。
- 8列・9列の両形式に対応しています（2026-10-03 追加。読み込み関数は01と同じ）。

### 03_旧キャビ_3センサ用_算出と可視化
（旧名: `修士一年次作成_抽出から加工_最終版.ipynb`。修士1年次に作成）
- 旧キャビ（CH02・CH03・CH04の3センサ）用です。12列のCSVを読み、横軸は射出率(cm³/s)です。
- 区間23・34・24（L23 = 22.4、L34 = 33、L24 = 55.4 mm）の3区間について計算します。L34 = 33 は旧キャビの値です。
- 平均・標準偏差を出すのはせん断速度γ23だけです（9行ごと）。グラフは30行ごとのブロック単位で作ります。
- 出力ファイル名は01・02と同じ形式ですが、シート名は「射出率と〜の関係」です。
- 現行のCH03・CH04だけのデータには使えません。

## 注意点

### 1. CH04 が CH03 より先に立ち上がっているデータ（NRall の 0.5mm は修正済み）
計算式は「CH03 → CH04 の順に流れる」前提です。CH04 が先に立ち上がっている行があると、その行は次のようになります。

- 時間差・流速・流量が負になり、グラフ（縦軸は0から）に表示されない。
- せん断速度・樹脂粘度が負になり（01では幾何平均の計算で NaN になる）、両対数の粘度グラフに出ない。

`NRall_summary_rise_start_results.csv` では、もともと 0.5mm 条件の270行（27条件）がこの状態でした。2026-10-03 にデータ側で修正済みです。修正内容は次のとおりです（git diff で確認）。

- 0.5mm の270行で、CH03 と CH04 の「立ち上がり時間」と「立ち上がり圧力」を入れ替えた。
- 1〜3列目、8列目（立ち上がり時間差）、9列目（先行列圧力@後発列立ち上がり時）と、0.5mm 以外の行は変更していない。
- その結果、全行で CH03 が先に立ち上がり、8列目は CH04−CH03 と一致し、9列目は全行で「CH03 の圧力 @ CH04 立ち上がり時」を意味する。

新しい9列データで同じ現象があれば、01・02番がセル1で「警告: ○行でCH04がCH03より先に立ち上がっています」と表示します。その場合は、センサの配線やデータを確認し、今回と同じように修正してください。

### 2. 軸範囲の外にある点はグラフに描かれない
軸範囲はセル5の `MANUAL_AXIS_LIMITS` で固定されています。範囲の外に出た点やエラーバーは、警告なしにグラフから切れます。新しいデータ（材料・温度・射出速度が違うもの）を処理したら、`{CSV名}_aggregated_summary.csv` の最小値・最大値が「軸範囲の現在値」の表に収まっているか確認してください。収まっていなければセル5の値を広げます。01と02は同じ値にそろえておくと、グラフを比べやすくなります。

### 3. 出力は上書きされる
01・02（と03）は同じ名前で出力するため、同じCSVに別のノートブックを実行すると前の結果が上書きされます。両方の結果を残したい場合は、CSVを別フォルダにコピーしてから実行してください。

### 4. ノートブック内に残っている実行結果について
01番の出力はクリア済みです。02番と03番に残っている出力は、改名前に別のCSV（02: `NR_summary_rise_start_results.csv`、03: `FUTABA1_summary_rise_start_results.csv`）で実行したときのもので、NRall の結果ではありません。
