# コードフォルダ 説明書

作成日: 2026-10-02

## このフォルダのコードでできること

圧力センサの立ち上がり抽出結果をまとめたCSV（`*_summary_rise_start_results.csv`）を読み込み、CH03–CH04 区間の物理量を算出して、CSV・Excel・PNGグラフに出力します。

| 量 | 単位 | 算出式 |
|---|---|---|
| 時間差 ΔT34 | s | CH04立ち上がり時間 − CH03立ち上がり時間 |
| 圧力差 ΔP34 | Pa | (CH03圧力@CH04立ち上がり時 − CH04立ち上がり圧力) × 10⁶ |
| 流速 V34 | mm/s | L34 / ΔT34 |
| 流路断面積 A | mm² | キャビ厚 h × 40 |
| 流量 Q34 | mm³/s | V34 × A |
| 樹脂粘度 η34 | Pa・s | ΔP34 · A · h² / (12 · L34 · Q34) |
| せん断速度 γ34 | 1/s | 6 · Q34 / (A · h) |

L34 は CH03–CH04 のセンサ間距離で、**正しい値は 17.5 mm** です。

## 結論：`NRall_summary_rise_start_results.csv` を処理するには

**`01_Futaba_抽出から加工_新キャビ版(グラフは平均と標準偏差).ipynb` を使ってください。** このCSVは9列形式で、9列形式に対応しているのは01番だけです。

1. VS Code で01番を開き、右上のカーネル選択で `.venv`（圧力立ち上がり抽出後_算出と可視化 (3.13.x)）を選ぶ
2. 「すべて実行」を押す
3. ファイル選択ダイアログで `データフォルダ/NR500/01_バージンPP再々実験/NRall_summary_rise_start_results.csv` を選ぶ
4. CSVと同じフォルダに結果が出力される（「出力ファイル」の節を参照）

> ⚠ このCSVの **0.5mm条件はすべて、時間差・流速・流量が負、樹脂粘度とせん断速度がNaN** になります。0.5mmだけCH04がCH03より先に立ち上がっているためです。詳しくは「注意点 1」を参照してください。

**順位の付け方**
- 入力ファイルへの前提（列数・行の並び・ショット数）が少ないほど上位。
- 全ショットを使うもの（平均・ばらつきが出る）を、1ショットだけ使うものより上位。

**目的別の選び方**
- 全ショットの平均とばらつきを見たい → **01**（データが10行ずつ整然と並んでいれば02でも計算結果は同じ）
- 10ショット目（定常状態）だけを見たい → **03**、または **05**
- 旧キャビ（CH02を含む3センサ）のデータ → **06**

## 対象ファイルの形式

### 共通ルール
- CSV（UTF-8 または Shift-JIS）で、1行目がヘッダー。
- 列名は**列の位置で付け直す**ため、列の順番が重要です（ヘッダーの文字そのものは問いません）。
- 温度は `元ファイル` 列から「数字＋℃」を読み取ります（例: `001_190℃_020_0.5mm.csv` → 190）。
- キャビ厚の列は数値（`0.5`）でも文字列（`0.5mm`）でも構いません。

### 8列形式（01〜05）　例: `NR_summary_rise_start_results.csv`
| 列 | 内容 |
|---|---|
| 1 | 元ファイル |
| 2 | キャビ厚 |
| 3 | 射出速度[mm/s] |
| 4 | CH03_立ち上がり時間(s) |
| 5 | CH03_立ち上がり圧力(MPa) |
| 6 | CH04_立ち上がり時間(s) |
| 7 | CH04_立ち上がり圧力(MPa) |
| 8 | CH03圧力@CH04立ち上がり時(MPa) |

### 9列形式（01のみ）　例: `NRall_summary_rise_start_results.csv`
| 列 | 内容 | 01番での扱い |
|---|---|---|
| 1〜7 | 8列形式と同じ | 同じ |
| 8 | 立ち上がり時間差(s)（絶対値） | 計算には使わず、そのまま保持 |
| 9 | 先行列圧力@後発列立ち上がり時(MPa) | 「CH03圧力@CH04立ち上がり時(MPa)」として計算に使う |

### 12列形式（06のみ・旧キャビ）　例: `FUTABA1_summary_rise_start_results.csv`
元ファイル, キャビ厚, 射出率(cm³/s), CH02/CH03/CH04 の立ち上がり時間(s)・立ち上がり圧力(MPa), CH03圧力@CH04立ち上がり時, CH02圧力@CH03立ち上がり時, CH02圧力@CH04立ち上がり時（MPa）
元ファイル名は `002_0.5mm_190℃.csv` の形式です。

## 共通の使い方（01〜05）

1. VS Code でノートブックを開く。
2. カーネルに `.venv` を選ぶ（pandas / matplotlib / xlsxwriter などはインストール済み）。
3. **上から順に**すべてのセルを実行する。セル2以降はセル1で読み込んだデータを使います。
4. セル1でファイル選択ダイアログが開くので、CSVを選ぶ。複数選択した場合はファイルごとに処理されます。ダイアログは最前面に出る設定ですが、見当たらないときは他のウィンドウの裏を確認してください。

### 出力ファイル（入力CSVと同じフォルダに作成。同名のファイルは上書き）

| ファイル | 作成するセル | 内容 |
|---|---|---|
| `{CSV名}_processed.csv` | セル4 | 全行＋全算出列 |
| `{CSV名}_aggregated_summary.csv` | セル3-1 | 1条件1行の集約（01/02/04/05: 平均・標準偏差・幾何平均・幾何標準偏差。03: 最終ショットの値） |
| `graph_output_{CSV名}.xlsx` | セル10 | グラフ画像を貼り付けたExcel（5シート） |
| `graph_images_{CSV名}/<シート名>/*.png` | セル10 | Excelと同じグラフのPNG |

Excelのシートは「射出速度と時間差の関係」「射出速度と流速の関係」「射出速度と流量の関係」「射出速度と圧力差の関係」「せん断速度と樹脂粘度の関係（両対数）」の5つです。各シートには、キャビ厚ごとの温度別個別グラフと総合グラフ、最後に全データの総集編グラフが入ります。

## 各コードの詳細

### 01_Futaba_抽出から加工_新キャビ版(グラフは平均と標準偏差)
- キャビ厚・温度・射出速度の組合せでグループ化し、グループ内の全ショットから次を計算します。
  - 時間差・流速・流量・圧力差: 平均と標準偏差
  - せん断速度・樹脂粘度: 幾何平均と幾何標準偏差
- ショット数が条件ごとに違っても、行の並びが崩れていても正しく集計できます。データが1件しかない条件は警告を出します（標準偏差がNaNになるため）。
- **8列・9列の両形式に対応**（2026-10-02 追加）。9列形式では、CH04がCH03より先に立ち上がっている行数を警告します。
- 両対数グラフの軸範囲: x 1〜10⁵、y 1〜3×10⁴
- 名前に「Futaba」とありますが、NRのデータにも使えます（NRのデータで実行した実績があります）。

### 02_抽出から加工_新キャビ版(グラフは平均と標準偏差)
- 先頭から10行ずつを1条件とみなし、平均・標準偏差を計算します（グラフの内容は01と同じ）。
- 10行に満たないブロックや、ブロック内で射出速度が混ざっている場合はエラーで停止します。
- 1条件10ショットで条件ごとに並んだデータなら、計算結果は01と同じになります。
- 両対数グラフの軸範囲: x 0〜10⁵、y 1〜10⁴

### 03_Futaba_10shot目のみ_抽出から加工_新キャビ版
- 条件（キャビ厚・温度・射出速度）ごとに**最後の1行だけ**を使います。平均・標準偏差は計算しません。
- グラフはエラーバーなし、`aggregated_summary.csv` は条件ごとの値そのものです。
- 条件ごとの行数が違っても動きますが、「最後の行」が使われるので行の順番に注意してください。
- 両対数グラフの軸範囲: x 1〜10⁵、y 1〜3×10⁴

### 04_10shot目のみ_抽出から加工_新キャビ版
- 10行ごとのブロックから10行目を取り出して10回複製し、02と同じ処理をします。そのため平均＝10ショット目の値、標準偏差＝0（エラーバーの長さ0）になります。
- **L34 が 33 になっています。使う前にセル2の `distance_L34 = 33` を `17.5` に直してください。**
- 両対数グラフの軸範囲: x 10〜10⁵、y 1〜10³

### 05_NR_抽出から加工_新キャビ版v2
- 04と同じ処理で、L34 = 17.5（正しい値）です。両対数グラフの軸範囲だけが違います（x 0〜10⁵、y 1〜10⁴）。
- 04より前の版です。

### 06_修士一年次作成_抽出から加工_最終版
- 旧キャビ（CH02・CH03・CH04の3センサ）用です。12列のCSVを読み、横軸は射出率(cm³/s)です。
- 区間23・34・24（L23 = 22.4、L34 = 33、L24 = 55.4 mm）の3区間について計算します。
- 平均・標準偏差を出すのはせん断速度γ23だけです（9行ごと）。グラフは30行ごとのブロック単位で作ります。
- 出力ファイル名は01〜05と同じ形式ですが、シート名は「射出率と〜の関係」です。
- 現行のCH03・CH04だけのデータには使えません。

### main.py
- `uv init` で自動生成されたテンプレートで、「Hello from sankasi!」を表示するだけです。データ処理には関係ありません。

## よく変更する設定（01〜05）

セル番号はノートブック内の見出しコメント（`# セル2: …` など）に合わせています。

| 設定 | 場所 | 内容 |
|---|---|---|
| `distance_L34` | セル2 | CH03–CH04 センサ間距離 [mm]。**正しい値は 17.5** |

| `MANUAL_AXIS_LIMITS` | セル5 | シートごとの軸範囲と目盛間隔。キー `0, 1, 2, 3` はキャビ厚の小さい順、`'default'` は全キャビ厚共通、`'all_data'` は総集編グラフ |

| `FIGSIZE_*` | セル5 | グラフのサイズ |
| `colors` | セル10 | 温度ごとの色（低い温度から順に割り当て） |

## 注意点

### 1. NRall の 0.5mm 条件では CH04 が先に立ち上がっている
`NRall_summary_rise_start_results.csv` の 0.5mm 条件（270行・27条件）は、すべて CH04 が CH03 より先に立ち上がっています（1.0〜2.0mm はすべて CH03 が先）。計算式は「CH03 → CH04 の順に流れる」前提なので、0.5mm では次のようになります。

- 時間差・流速・流量が負になる。グラフの縦軸は0からなので表示されない。
- せん断速度・樹脂粘度は対数をとれず NaN になり、粘度グラフに出ない。
- 圧力差は正の値になり、表示される。

0.5mmで本当にCH04→CH03の順に流れているのか、立ち上がり検出の誤りなのかを確認してください。正しい現象であれば、時間差を絶対値にするなど計算式の修正が必要です。その場合、9列目「先行列圧力@後発列立ち上がり時」は0.5mmでは「CH04の圧力@CH03立ち上がり時」を意味するので、圧力差の引く側も CH03 の立ち上がり圧力にすると整合します（どちらも閾値付近の約0.3MPaなので、数値への影響は小さいです）。

### 2. 02〜05番で9列CSVを使う場合
そのまま読み込むと、列名の付け直しがスキップされ、セル2で `KeyError: 'キャビ厚'` が出て止まります。Excel などで8列目「立ち上がり時間差(s)」を削除して8列にしてから読み込んでください。

### 3. 出力は上書きされる
01〜05はどれも同じ名前で出力するため、同じCSVに別のノートブックを実行すると前の結果が上書きされます。両方の結果を残したい場合は、CSVを別フォルダにコピーしてから実行してください。

### 4. ファイル名の「NR」「Futaba」は成形機を限定しない
01〜05は列形式さえ合えば、NR500・Futaba どちらのデータにも使えます。

### 5. ノートブック内に残っている実行結果について
各ノートブックに残っている出力は、改名前に別のCSVで実行したときのものです。今回のデータの結果ではありません。
